# 第3批交付与验收（2026-11-08）

本批实现K1–K11分类与标签，累计20/67个业务端点。前端继续使用Mock；真实Service适配及页面联调仍按第9批实施。未新增API、运行时依赖或数据库表，也未修改SQL结构或追加备份。

## 接口及结果

| 接口 | 行为 |
| --- | --- |
| K1 GET /categories | 平台+本人自定义分类；管理员可看全部；扁平数组含parentId/custom/ownerId/desc/paperCount |
| K2 POST /categories | 普通用户创建自有项，管理员创建平台项；归属不接受客户端指定 |
| K3 PATCH /categories/{id} | 重命名；普通用户仅可改本人项；唯一冲突409 |
| K4 DELETE /categories/{id} | 删除同归属子树并返回根到后代的名称数组；仅解除论文分类关联 |
| K5 POST /categories/{id}/move | parentId显式number或null；防自身/后代环、跨归属挂接和深度超限 |
| K6 GET /categories/{id}/papers | 含后代，SQL先按可见性及未删除过滤，按uploaded_at/id倒序 |
| K7 GET /tags | 平台+本人标签；管理员可看全部；包含可见论文paperCount |
| K8 POST /tags | 角色决定归属；名称按归属唯一 |
| K9 PATCH /tags/{id} | 修改名称和颜色；保留既有归属 |
| K10 DELETE /tags/{id} | 删除标签并解除该标签关联，保留论文和其他标签 |
| K11 GET /tags/{id}/papers | 可见关联论文数组，不重复论文 |

名称1–50字符，颜色为#RRGGBB（响应规范为大写）；ID必须为正JS安全整数。未知字段、ownerId/custom等越权字段、非法父级及不完整移动请求均拒绝。不存在或其他用户的自定义项返回404；普通用户修改平台项返回403。

分类最多10层，创建和移动都校验；移动同时计算整棵子树高度。平台分类只能挂在平台分类下；自定义项可挂平台或同归属自定义项，管理员修改他人分类也遵守其原归属。已有脏环、缺失父级、超深树会快速返回409，不交给前端递归导致挂死。

平台子树含用户自定义节点时，删除返回409，要求先移动这些节点；管理员可以单独移动、编辑、删除用户自定义项。保留“最高读取/管理权限”及“禁止未经验证跨归属级联”的既有规则。

## 可见性、计数与审计

普通用户只统计/返回本人未删除论文及approved共享论文；他人的私有、待审、驳回、下架以及所有逻辑删除论文不计入。分类计数沿唯一父链向上累加，每篇在每个祖先仅计一次；标签按真实关联计数。

管理员的可见范围包括所有未删除私有与共享论文，因此K1/K7计数也包括这些论文。管理员读取自定义分类/标签元数据、私有论文计数及K6/K11私有论文列表，先在独立事务写审计，失败不返回数据。按资源ID及ownerId留痕，不记录名称、摘要或笔记正文；批量资源审计同一独立事务全部成功后才返回。外层事务回滚不撤销审计。

论文数组复用统一PaperViewFactory，批量读取上传者姓名和标签关联，每批最多500个ID；避免逐篇调用详情接口。隐藏filePath/fileSha256/version等内部字段，reviewComment仅本人和管理员可见。

前端管理员分类/标签页的旧文案仍有“共享论文”描述，第9批接入时应按此统一可见范围调整文案；本批没有改变页面流程。

## 并发及事务

分类树修改先按主键顺序FOR UPDATE读取当前整树。论文上传、编辑先对分类及标签字典取共享锁，再锁论文；上传的PDF解析在取字典锁之前完成。标签修改/删除先锁目标标签；删除分类或标签时按升序逐个锁受影响论文主键。

统一顺序为“分类/标签 → 论文”，避免上一批编辑先锁论文、再检查分类时与字典删除形成反向等待。当前规模使用整树/字典共享锁，锁范围较宽，后续数据规模增加需结合压测细化锁粒度。并发唯一键及锁冲突返回409，禁止以重试覆盖已提交结果。

分类/标签变更、关联解除、受影响论文version递增和成功日志同事务。删除关联同时处理逻辑删除论文的残留引用；不删除PDF、收藏、阅读、笔记或处理历史。平台分类/标签维护不把approved论文重新送审；显式U3编辑仍沿用自动转pending规则。

锁机制依据[MySQL 8锁定读说明](https://dev.mysql.com/doc/refman/8.0/en/innodb-locking-reads.html)，并已在真实MySQL中验证互相移动、删除与编辑竞争及回滚；没有使用内存锁替代跨连接数据库锁。
