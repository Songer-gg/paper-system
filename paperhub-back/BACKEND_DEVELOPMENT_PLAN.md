## 前端接入清单

- 保留 src/services 对页面的入口，用真实适配器调用 paperhub-api/ts/modules；在适配器绑定 ApiClient。模块函数多一个 client 参数，不直接替换页面 import 后声称零改动。
- 登录将 {token,user} 存入会话；remember 决定 local/session，先清除另一处旧值；token 失效清除会话及个人缓存。
- getFavoritePaperIds 属于前端缓存选择器：首次加载 R1 后初始化，以 R2 返回目标状态更新；getFavoritePapers 映射 R1 中非空 paper，不另建端点。
- getVisiblePapers 用 U1 + 分页拉取 U10 组合去重；未来数量增长再引入搜索选择器，不为 Mock 函数机械增加全量接口。
- getMyProfile 的旧 uploadedCount 参数不发给后端，改由 P1 返回；头像传 File。阅读记录、筛选项按 Promise 消费。
- P4成功后清理会话及个人缓存并重新登录；M6密码重置只展示本次响应，不做自动重试。M5重复设置相同状态不递增版本，但恢复账号后旧token仍失效。
- 举报列表/处理记录直接显示ReportItem.paperTitle快照及reporterName，不再用共享论文当前标题或Mock姓名重建历史；保留paperId用于可访问详情导航。设置页从M25读取只读信息，保存按钮只作只读提示；日志页从M24读取真实记录并使用精确action筛选，不新增写接口。
- 首页/统计从P5/P6/M1获取聚合，不再在浏览器用Mock或全量论文拼图表。管理员共享卡片只计approved；今日/趋势包含全部未删除共享状态。去除“含1名已禁用”“较昨日+2”等静态提示；分类分布使用后端根分类归属，个人缓存不跨账号复用。
- 分类标签读取 K1/K7 的 paperCount；加载平台/个人字典缓存供标签、分类路径展示。Paper.uploaderName、审核/举报/处理人展示字段由 VO 关联，不调用管理员用户接口给普通用户解析名称。
- 404/1003 由适配器按详情页约定转为空态，其余错误展示真实 message，finally 收尾 loading；不把请求失败当作用户取消。
- 用真实 U8/U9 取 Blob，正确解析 JSON 错误；不把 Bearer token 放 URL。下载用 attachment，预览正确处理对象 URL 释放。

## 必测场景

1. 两用户上传同一共享 DOI/哈希：提交竞争只产生一个活动共享资源；相同私有文件可各自保存。
2. 审核通过与上传者撤回并发：只能有一个合法转换，不能留下已公开但用户已撤回的资源。
3. 管理员查看私有文件/他人笔记先记审计；审计失败不返回敏感正文。
4. 删除被收藏、被阅读、已有笔记和举报的论文：PDF 立即失效，个人笔记和历史仍可读。
5. 用户禁用/改密/重置后携带旧 token 调用接口：拒绝；账号恢复不复活旧 token。
6. 两个分类同时互相移动，或平台节点下存在自有节点：不成环、不越权级联。
7. 文件持久化后数据库失败，以及数据库提交后文件清理失败：可补偿，不出现公开残留路径。
