## 接口范围

| 接口 | 行为 |
| --- | --- |
| P1 GET /me/profile | 本人资料、受控头像dataURL、未删除论文上传数 |
| P2 PATCH /me/profile | 仅部分更新本人姓名/邮箱，邮箱唯一 |
| P4 PUT /me/password | 校验旧密码、确认新密码，BCrypt及版本递增 |
| M2 GET /admin/users | 姓名/用户名关键字、状态和注册日期筛选，含共享/贡献计数 |
| M3 GET /admin/users/{id} | 安全用户详情，含passwordResetAt |
| M4 GET /admin/users/{id}/papers | 全部未删除上传，含私有，返回前审计 |
| M5 PATCH /admin/users/{id}/status | 启用/禁用，实际变化撤销旧会话，管理员账号保护 |
| M6 POST /admin/users/{id}/password-reset | 一次响应随机新密码，更新哈希、时间及会话版本 |
| M26 GET /admin/users/{id}/favorites | 全部收藏记录，删除来源paper=null |
| M27 GET /admin/users/{id}/reading-records | 全部阅读记录，含安全paper或null |
| M28 GET /admin/users/{id}/notes | 全部私人笔记及历史标题快照，删除来源占位 |

路径前缀均为/api/v1。/me始终指JWT主体，不接受userId切换身份；管理路径需真实管理员。不存在用户返回404/1003。所有响应不暴露password、tokenVersion、头像文件键或论文存储路径。

## 资料与密码

P2拒绝空对象、显式null、数字冒充字符串及任何归属/角色/头像/密码字段。姓名按Unicode字符限制1–50，邮箱去首尾空白转小写、校验格式及120字符上限；先检查已有邮箱/邮箱式username，数据库唯一键兜底并发冲突。只更新提供的字段，保留头像、密码及其他资料；资料变更不撤销当前会话。

P1/P2返回与P3一致的受控PNG dataURL；读取限定内部头像键及大小，缺失文件返回空字符串。uploadedCount只统计本人未删除论文，包含私有和全部共享状态。

P4按8–72 UTF-8字节验证新密码，保留原始空格，不trim；确认不一致、旧密码错误、与旧密码相同返回400/1006，格式错误返回422/1005。锁定当前账号后核对当前哈希，防止并发请求都用旧哈希修改成功。BCrypt哈希、token_version递增和成功日志同事务；原passwordResetAt保留。成功返回{ok:true,message}后，当前及其他设备旧token均不可用，前端真实适配须清理会话并重新登录。

M6使用SecureRandom的18字节随机源（144位），编码为24字符密码；仅本次string响应显示。数据库只存BCrypt哈希，password_reset_at与token_version同事务更新；成功日志不含密码或哈希。重复点击会生成另一新密码，不允许前端自动重试。

## 用户管理与并发

M2关键词按姓名/用户名查找，LIKE特殊字符按字面匹配。日期严格yyyy-MM-dd，两端日期包含当日00:00:00–23:59:59，拒绝无效日期及逆序范围。排序为registeredAt/id倒序。sharedCount排除私有和已删除资源但包含全部共享状态；contributionCount仅approved未删除共享。

M5禁止自禁用和禁用最后一个可用管理员。账号状态/重置操作按主键顺序锁管理员，再锁目标普通账号，锁定后重验操作者仍为可用管理员，防止已被另一管理员禁用的在途请求继续交叉禁用。当前主键扫描在默认隔离下可能锁住扫描范围，管理写操作有意串行化；未来新增角色修改须遵守同一锁序，不将此机制描述为无范围锁。

状态真正改变才递增版本，重复设置相同状态保留版本；恢复账号再次递增，旧token不会复活。用户状态、哈希、重置时间和成功日志故障整体回滚；不获取论文或字典锁。

## 管理员个人数据访问

M2/M3和M4/M26–M28先独立持久化用户范围审计，空个人列表也记录访问；逐条私人收藏/阅读/笔记和私有来源另留资源审计。任一审计失败都不返回敏感响应，已完成的范围审计不随外层失败回滚。日志记录操作者、资源ID、所属用户、动作、时间和结果，不含正文、密码或哈希。

管理员可查看未删除的私有、待审、驳回或下架来源，因此M26/M27中的这些paper仍可非空；已删除来源为null。M28按管理员权限计算paperAvailable，删除论文仍保留笔记正文与原paperTitle，不随源论文改名重建。/me仍仅返回管理员自己的数据，R8/R9不能用于修改别人的笔记。
